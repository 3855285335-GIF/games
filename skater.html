怎么玩

两根手指按在滑板上：靠板尾的是后脚，靠板头的是前脚。按在板子外面的手指不算，手指滑出板子就脱板。
↑
两指往板头方向推 = 蹬地，推出板头就抬起来放回去再推。手指压在板子右/左半边 = 右/左转，两指在板上旋转也能转。
↓
后指快速往下划出板尾 = 起跳 Ollie，划得越快跳得越高。前指快速往下划 = Nollie。
←
→
跳起来后：前指从板边侧划出去 = Kickflip / Heelflip；后指侧划 = Shove-it；两种一起 = Varial、360 Flip…；两指旋转 = 空中转体。
落地前把手指放回板上接住（板子周围出现黄圈就是提醒你接板）。板子没翻完、歪着落地也会摔。
只用一根手指按住板尾 = Manual，越靠板尾翘得越高，让指针停在绿色区；按住板头 = Nose Manual。
⇉
两指一起往同一边横甩 = Powerslide 急停。在碗池、U 台下坡时两指按稳在板上 = 压板加速，可以一直来回滑。
跳到杆子、台子边、池边上自动磨杆；招式之间不落地或用 Manual 连起来，分数翻倍。
⌨️
电脑：W/S 加速刹车，A/D 转弯，空格 跳，J/L 翻板，K/I 转板，Q/E 转体，M Manual，X Powerslide，R 复位。
