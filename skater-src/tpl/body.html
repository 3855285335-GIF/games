怎么玩

两根手指按在滑板上：靠板尾的是后脚，靠板头的是前脚。一开始就按在板子外面的手指不算；按在板上以后，滑出板边一点也还算，滑得离板子太远才会脱板。
↑
手指往板头方向划一下 = 蹬一脚，划短也有用，划出板头也照样算；抬起来放回板上再划。
↷
压板转弯：手指往板子右半边压，板面往右倾、沿弧线往右拐；压得越靠边弯越急。和真滑板一样，滑得越快弯越大，停着压板不会转。停着或很慢时：一指按住板尾，另一指往旁边拨 = Kickturn 原地转向。
↓
后指往板尾快划一下再松手 = 起跳 Ollie：松手的那一刻才跳，划得越快跳得越高。前指快速往下划再松手 = Nollie。
←
→
先拨再跳：前指先从板边侧拨出去（板子先不动），紧接着后指划板尾、松手，起跳的同时 Kickflip / Heelflip；后指侧着划出去再松手 = Pop Shove-it；两种一起 = Varial、360 Flip…；两指旋转 = 空中转体。板子每次都转完整的圈，停在正的位置。拨得越重圈数越多，跳得越高能转得越多（两圈、三圈……）。从坡上飞出去时在空中拨也能翻。
落地前把手指按回板上 = 接板。板子快转完时黄圈会亮，这时按回去脚会顺手把板带正；板子刚转起来就按回去会把板踩停，落地会摔。板子转完的那一刻接住 = 踩点，多给分。
只用一根手指按住板尾 = Manual，越靠板尾翘得越高，让指针停在绿色区；按住板头 = Nose Manual。
⇉
两指一起往同一边横甩 = Powerslide 急停。在碗池、U 台下坡时两指按稳在板上 = 压板加速，可以一直来回滑。
靠近杆子、台子边、池边时那段会亮起来：两指同时按住不动就自动跳上去磨，手指按着就一直磨，松开跳下来；自己起跳落到杆上也能磨。招式之间不落地或用 Manual 连起来，分数翻倍。磨杆时前指按住、后指往旁边一划，板子在杆上转 90° 变 Boardslide，再划一下转回来；在杆上先拨板再起跳 = Kickflip Out。杆子是实心的，撞上会弹开，磨不上又落在杆子上会挂住摔倒。
🛑
Stall：跳向台子边或者冲到坡顶时，空中只留前指（或只留后指）按在板上，板头（板尾）落到边上会卡住停下；松手退回来，后指往板尾一划就跳上去。两指一起往板尾划 = Impossible，板子竖着绕后脚翻一圈。
🏁
限时 100 秒：100 秒里拿多少分；连续：不限时，摔一次就结算，比谁一口气拿的分多。两种各有排行榜。
⌨️
电脑：W/S 加速刹车，A/D 压板转弯，Z/C 原地 Kickturn，空格 跳（V 轻跳），J/L 起跳 + 翻板，K/I 起跳 + 转板（按住 Shift 是用力拨，转两圈），U Impossible，Q/E 转体，M Manual，X Powerslide，按住 G 磨杆，R 复位。
