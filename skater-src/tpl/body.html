怎么玩

两根手指按在滑板上：靠板尾的是后脚，靠板头的是前脚。一开始就按在板子外面的手指不算；按在板上以后，滑出板边一点也还算，滑得离板子太远才会脱板。
↑
手指往板头方向划一下 = 蹬一脚，划短也有用，划出板头也照样算；抬起来放回板上再划。
↷
压板转弯：手指往板子右半边压，板面往右倾、沿弧线往右拐；压得越靠边弯越急。和真滑板一样，滑得越快弯越大，停着压板不会转。停着或很慢时：一指按住板尾，另一指往旁边拨 = Kickturn 原地转向。
↓
后指快速往下划出板尾 = 起跳 Ollie，划得越快跳得越高。前指快速往下划 = Nollie。
←
→
跳起来后：前指从板边侧划出去 = Kickflip / Heelflip；后指侧划 = Shove-it；两种一起 = Varial、360 Flip…；两指旋转 = 空中转体。
落地前把手指放回板上接住（板子周围出现黄圈就是提醒你接板）。板子没翻完、歪着落地也会摔。
只用一根手指按住板尾 = Manual，越靠板尾翘得越高，让指针停在绿色区；按住板头 = Nose Manual。
⇉
两指一起往同一边横甩 = Powerslide 急停。在碗池、U 台下坡时两指按稳在板上 = 压板加速，可以一直来回滑。
靠近杆子、台子边、池边时那段会亮起来：两指同时按住不动就自动跳上去磨，手指按着就一直磨，松开跳下来；自己起跳落到杆上也能磨。招式之间不落地或用 Manual 连起来，分数翻倍。
⌨️
电脑：W/S 加速刹车，A/D 压板转弯，Z/C 原地 Kickturn，空格 跳，J/L 翻板，K/I 转板，Q/E 转体，M Manual，X Powerslide，按住 G 磨杆，R 复位。
